# PLCYard

PLCYard is a free, open-source PLC trainer. You write a program in ladder (LD), structured text
(ST) or function block diagram (FBD), run it on a simulated PLC wired to an animated machine, and
check it against the written requirements of an exercise.

- **[Try it in your browser](https://juliordz.com/plcyard/app/)**: ladder and structured text, I/O
  panel, silo, traffic lights and tank, exercises 1-13, nothing to install.
- [Download and install](download.md), then start with [Getting started](getting-started.md).
- How the PLC runs your program: [The scan cycle](scan-cycle.md).
- Two ways to write the same program: [Notations](notations.md).
- The editors: [Ladder](ladder.md), [Structured text](structured-text.md),
  [Function block diagram](fbd.md).
- Data: [Tags, data types and arrays](tags.md). Program structure: [Routines and blocks](routines.md).
- Every instruction, block, function and simulation: the **Reference** section, generated from the
  code so it always matches the program you run.
- Want to add an exercise or a machine? See [Writing exercises](writing-exercises.md),
  [Adding a simulation](adding-a-simulation.md) and [Contributing](contributing.md).
