PID¶

Every loop update time (UPD) while the rung is true. The process variable is scaled from MINI..MAXI to MINS..MAXS (engineering units), the output in % goes to the control variable scaled to MINCV..MAXCV. Optional: a setpoint (else the SP member), a tieback the output follows in manual, a master loop whose output (in %) becomes this loop's setpoint (cascade), and an inhold bit that holds the output at the inhold value (bumpless restart). PID Setup in the editor sets the members.

CALL¶

A function by name, a function block by its instance (Motor1, or #Inner inside a block). Parameters: Start:=Button (input) or Running=>Lamp (output). EN → ENO.
